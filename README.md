# Riftformat Tools

This repository is a prototype built to demonstrate the intention of the Riftformat Tools project. It currently uses the community RiftScribe API, and the end goal is to replace it with the official Riot API for Riftbound.

The prototype is a small Python tool that generates a random, correctly formatted Riftbound decklist. It picks a random Legend, add its Chosen Champion, fills the main deck from the Legend's two domains, add three Battlefields, and split 12 Runes between the domains.
